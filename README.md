# pascalsene.github.io

Site GitHub Pages personnel qui héberge **Neon Tetris Retro**, un Tetris rétro au style néon jouable directement dans le navigateur.

## Jouer

Ouvrez le site GitHub Pages du dépôt (*Settings > Pages* indique l'adresse publiée).

## Contenu

| Fichier | Rôle |
|---|---|
| `index.md` | Le jeu complet (HTML, CSS et JavaScript dans un seul fichier) |

Le jeu charge la police *Press Start 2P* depuis Google Fonts.

D'autres jeux et simulateurs dans le même esprit sont regroupés dans le dépôt [html](https://github.com/darkw0lf/html).
